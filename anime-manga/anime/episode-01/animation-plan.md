## Generation policy
Credit-consuming generation requires explicit per-batch approval. Before any run:
what is generated, which model, expected credit cost, and a confirmation request.

Standing approval for a session applies only if the author grants it explicitly,
and lapses at the end of that session.

## Shot generation order
1. Establishing shots (lock the look of the location in motion)
2. Character-defining shots (lock the look of the character in motion)
3. Dialogue coverage
4. Action sequences
5. Transitions

Short shots only. No attempt to generate a sequence, scene or episode in one go.

## Continuity in motion
| Risk | Control |
|---|---|
| Character drift between shots | Same reference set every shot; re-approve on change |
| Lighting jumps between shots | Lighting locked per sequence, recorded in the shot list |
| Eyeline / screen-direction breaks | 180-degree rule inherited from the manga page plan |
| Costume/prop changes mid-scene | Checked against the character file, not the previous shot |
