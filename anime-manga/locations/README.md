# Locations — CARTHAGE SAGA

**Status:** `PROPOSED` index in place, mirrored from `story/world.md`.

One file per recurring location: `LOC-XX-<name>.md`. Copy `_TEMPLATE-location.md`.
A location appearing in more than one scene needs a reference sheet before it is drawn.

**Every location file fixes its establishing angles.** A location is only ever established from the
two or three angles named in its file, so that the reader builds a stable mental map across a
six-hundred-year story. This matters more here than in most series, because places recur
centuries apart — Tyre in ch. 1 and ch. 170, Carthage across all eight Books.

## Sub-location note

`LOC-01` contains the **rope walk**, which is chapter 1's entire set and is specified inside the
Tyre file rather than given its own ID. The same pattern applies elsewhere: a set that appears in
only one arc lives inside its parent location file.

## Production order

Locations are built in chapter order, not index order. For Chapter 1, only `LOC-01` is required.
